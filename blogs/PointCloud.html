What are Point Clouds?

A point cloud is a set of data points in 3D space, typically produced by LiDAR, photogrammetry, or depth cameras. Each point has coordinates (x, y, z) and may include attributes like color or intensity. Point clouds are fundamental for representing complex geometries and environments in digital form.

Key idea: Point clouds capture real-world geometry in discrete samples, enabling accurate 3D reconstruction.

Acquisition Methods

  • LiDAR: Uses laser pulses to measure distances, producing dense point clouds for mapping and navigation.
  • Photogrammetry: Derives 3D points from overlapping 2D images using triangulation.
  • Depth Cameras: Devices like Kinect or stereo rigs generate point clouds from disparity or ToF measurements.

Processing Challenges

Point clouds are **unstructured and unordered**, making them harder to process than images. Algorithms must handle noise, varying density, and occlusions. Common tasks include:

  • Segmentation: Partitioning points into meaningful regions (e.g., ground vs. objects).
  • Classification: Assigning semantic labels to points (e.g., car, pedestrian, building).
  • Registration: Aligning multiple point clouds into a unified model.
  • Surface Reconstruction: Converting point sets into meshes or volumetric models.

Applications

Robotics

Point clouds enable robots to perceive environments, detect obstacles, and perform SLAM (Simultaneous Localization and Mapping).

Autonomous Driving

Self-driving cars use LiDAR point clouds for real-time perception, object detection, and navigation.

AR/VR

Point clouds reconstruct immersive environments for augmented and virtual reality experiences.

Healthcare

Medical imaging uses point clouds for 3D scans of anatomy, aiding diagnostics and surgical planning.

Industry

Point clouds support quality control, reverse engineering, and digital twins in manufacturing.
